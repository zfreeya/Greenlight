# 第一个愿意独立使用 Harness 并为它付钱的人，我准备怎么找到

日期：2026-08-29。这不是战略，是 30 天的找人之旅。目标只有一个：**一个人，独立跑通一个真实项目，为 Harness 付过钱（真转账，金额不论）**。

## 一、先定义这个人：三个条件，缺一不可

1. **有真实且重复的视频需求**，不是尝鲜。判断标准：他过去 3 个月花钱做过几次视频？次数 ≥ 3 才算。
2. **能独立操作**，有生产素养：知道镜头、时长、Take、导出是什么。判断标准：他能自己装软件、看懂分镜表、理解"重新生成"。
3. **有付费习惯和预算**。判断标准：他每个月为工具或外包花多少钱？≥ 500 元才算。

## 二、候选画像，按可能性排序

- **A. 广告/设计公司里负责视频执行的个人**：客户压需求、工具钱能转嫁给客户、生产素养高。最接近。
- **B. 短剧/短视频工作室的编导或后期**：量最大、最懂流程，但价格敏感。
- **C. 电商团队的短视频负责人**：需求最刚性，每周都要新素材，但未必愿意操作复杂工具。

第一个候选大概率是 A 或 A 和 C 的混合：给客户做视频、被外包拖过工期、自己动手能力强、为效率工具花过钱的人。

## 三、名单怎么来，从近到远

1. **现有交付客户里问一句**（第 1 周）："你自己想不想做？我教你怎么做，你做完试试。"服务客户里已经问过"你平时怎么做出来的"的人，就是最热的线索。
2. **身边具体的人**（第 1 到 2 周）：做剪辑的前同事、朋友公司里管内容的人，直接约，不群发。
3. **社群**（第 2 到 4 周）：AI 视频交流群、剪辑师群，话术只有一句："我做了个本地工具，免费给你用，条件是你要自己跑完一个真实项目。"一对一，比一对多有效。

不花钱投广告，不写公众号文章。这个阶段一个准用户比一百个访客值钱。

## 四、转化路径，三步，每步有验收

**第一步 试用（3 天）**：装打包版，用他自己的素材跑通一个 8 镜头项目。
验收：他能独立装、独立跑通。
这里卡住的每个地方都是产品需求，原样记下来。

**第二步 独立项目（1 周）**：给一个真实项目，你只观察，不代操作。
验收：他完成一个成片。中间求助你的次数、原因、耗时，全部记下来。

**第三步 收费（第 3 到 4 周）**：收工具使用费。
金额不是按功能定价，是按"他自己做省了多少钱"的零头。他的参照物是外包价，一条 1500 到 4000。工具月费收 300 到 500，不会疼。

## 五、环境门槛必须先跨，这是最容易被忽略的

现在 Harness 是开发态：要装 ffmpeg、配 API Key、跑 dev 版。外人第一步就劝退。所以：

1. 打包一个安装版（tauri build 已有基础，出 .app 或 .dmg）。
2. 写一份"从安装到第一条成片"的说明，要求 30 分钟内完成，写完之后自己按说明走一遍，卡住就改。
3. 把"让别人能装上"当成产品需求，不按技术兴趣排序。第一个独立用户遇到的每一步障碍，都是后来所有用户的障碍。

## 六、观察清单：独立使用时记什么

- 在哪一步卡住，卡了多久。
- 求助你的次数和原因，分五类：不会用、不知道状态、模型失败、怕花钱、东西丢了。
- 他用什么功能，忽略什么功能。
- 他愿不愿意自己修一个镜头。愿意，才是"独立"用户。

这些记录直接喂给 O5 的 KR2（Take 批准/拒绝原因）和看板的"单项目人工分钟数"。

## 七、30 天时间盒

- 第 1 周：定候选名单，至少 5 个具体的人名；打包安装版。
- 第 2 周：2 到 3 个试用，记录所有卡点。
- 第 3 周：1 个完成独立项目，记录求助次数。
- 第 4 周：收费尝试，金额小但要真实。
- 验收：30 天结束，有 1 个人独立跑通且付过钱，哪怕 1 块钱，要真转账记录。

## 八、如果 30 天没找到，说明什么（这是分析，不是失败）

- 三个候选都装不上：门槛问题，不是市场问题。先修打包和说明，不换人。
- 装上了但不会用：产品太复杂。回到"只产品化最高频的一个运营动作"。
- 会用但不愿付钱：画像错了。换一类人试，比如从电商负责人换到广告公司执行。
- 一个都没聊到：渠道问题。换触达方式，群发改一对一。

## 九、底线

这个人不是"用户增长"，是产品需求的第一个来源。他独立使用时每一步卡顿，都是需求文档。找到他的过程本身，就是产品化。

判断"找到了"只有两条硬标准：他独立完成过成片；他给你转过账。
